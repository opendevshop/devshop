# DevShop Host Management System

DevShop is a dashboard for managing websites.

This is a composer template, since every devshop is unique.

## Getting started

Use [DDEV](https://ddev.com) to run DevShop locally. Follow these instructions:

1. Install DDEV following the [documentation](https://ddev.com/get-started/)
2. Open the command line and `cd` to the root directory of this project
3. Run the following commands:
```shell
ddev start
ddev composer install
ddev launch
```

DevShop has the same system requirements as Drupal, so you can use your preferred setup to run it locally. [See the Drupal User Guide for more information](https://www.drupal.org/docs/user_guide/en/installation-chapter.html) on how to set up Drupal.
